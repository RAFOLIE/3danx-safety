# 验证范围

以下是去除个人文件名称、私人路径和场景校验值后的验证摘要。私人样本及完整本机检查记录不随仓库或发布包提供。

## 清理核心

- 5 个实际 CRP 感染场景副本均成功移除受支持的 CRP 记录。
- 每个副本的所有非 `Config` 数据流与清理前逐字节一致。
- 清理后的 `Config` 与独立清理实现的输出一致。
- 清理前备份与原件字节一致。
- 追加式 CRP 启动脚本尾部可以移除，正常前缀保留。
- 无感染文件、无效结构及无法精确分离的脚本尾部不会被修改。
- 实际感染原件没有被加载到 Max 执行。
