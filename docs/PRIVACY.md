# 隐私与发布内容

本工具不建立网络连接，不上传场景文件、备份、日志或使用记录。

运行过程中，数据只保存在当前用户的 `%LOCALAPPDATA%\3danxSafety`：

| 数据 | 内容 |
| --- | --- |
| `settings.ini` | 自动清理、成功静默选项 |
| `3danxSafety.log` | 本地检测与清理结果，可能包含完整文件路径 |
| `Backups/` | 清理前原件、原始路径及文件校验值 |
| `installation.json` | 本地安装文件位置 |

这些本地文件可能含用户名、项目名或感染代码，应由使用者自行保管。本仓库的忽略规则排除了模型、备份、运行日志和本地验证记录；发布包通过明确的文件清单生成。

公开仓库只发布工具源码、清理核心、安装与设置入口、通用文档。原始场景名称、模型内容、场景校验值、私人磁盘路径、本机用户名和原始检查报告均不在公开内容中。
